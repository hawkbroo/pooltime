# POOL TIME CLUB

Сайт бильярдного клуба (Краснодар, ул. Российская, 79/4).

Статика HTML/CSS/JS + `content.json` и мини-админка для меню, цен, фото столов и акций.

## Запуск локально

```bash
py -3 serve.py
```

Открой: http://127.0.0.1:5560/

Админка: http://127.0.0.1:5560/admin/  
Пароль по умолчанию: `pooltime2026` (смени перед передачей клиенту).

## Структура

- `index.html`, `styles.css`, `script.js` — публичная страница
- `content.json` — тексты, меню, цены, скидки
- `admin/` — панель редактирования
- `serve.py` — локальный сервер с сохранением JSON и загрузкой файлов
- `img/logo.png` — логотип
- `uploads/` — загруженные фото (акции, столы)

## Хостинг

Для РФ удобно Beget (обычный PHP/static или Python). Cloudflare/`workers.dev` для РФ лучше не использовать.
